# Summary

The four-page paper that defines the updating rule Part Two rests on. A group holds beliefs, each
member weights the others, everyone revises to their weighted average, and the process repeats.
Under the standard connectivity and aperiodicity conditions the beliefs converge, and the consensus
is the normalized left stationary vector of the trust matrix applied to the initial beliefs. That
vector is what this project calls influence, and its maximum entry is the quantity Golub and
Jackson's theorem constrains.

**Status.** Read at source and long used by the project; `research/SOURCES.md` has recorded it as
read since before this corpus existed. What was missing was a corpus record, which this supplies.

**The document is not archived here.** The located PDF's posting authorization is unverified and
the project's rights review directs that it not be archived. It also has no text layer, so it could
not support a verification index or a machine-checked quotation even if it were archived. Chapter 7
uses the updating rule, which is standard mathematics restated in the project's own notation rather
than quoted.
